A tiny stack VM for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty ($100 USDC). Runs each `program.bin` on its `input.bin`, writes `stdout.bin` + `exit.txt`. Full ISA: wrapping 32-bit arithmetic, all ten traps, step/output limits.
